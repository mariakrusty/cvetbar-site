# Цветочный бар — прототип сайта (на согласование)

Концепт-прототип главной страницы и карточки товара для «Цветочного бара».
Регистр: тёмный кинематографичный, палитра какао + молочный, кобальт-акцент.

- `index.html` — главная (герой-видео, «Свежий сбор», каталог, SEO-блоки, футер)
- `card-anturium.html` — карточка товара (плёнка из 5 кадров + live-видео)

Прототип для визуального согласования. Финальная вёрстка — на платформе OpenCart.
